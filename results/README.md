# Derived results

Tables behind the paper's numbers. `experiments/07_figures/figures.py` reads them when the raw run archives are not attached.

| File | Content | Produced by |
|---|---|---|
| `numbers.json` | every number in Figures 1-4 (SWE-rebench silence, fix-site breakdown, E1, E2), with bootstrap intervals | `07_figures/figures.py` |
| `swe_rebench_tasks.csv` | one row per SWE-rebench candidate (150): status, old tests executing the fix site, confirmed flips, localization ranks, planted-bug catch rates by test set | `04_swe_rebench` (`swelib.report`) |
| `e1_gemma_localization.csv` | one row per E1 prompt (387): task, candidate source, whether the fix was among the candidates, Gemma's top-1 / top-3 | `05_gemma/e1_e2_generate_gemma.py` |
| `e2_gemma_patch_samples.csv` | one row per Gemma answer (440): valid, no-op, F2P / harness / visible-test outcomes | `05_gemma/e2_grade_patches.py` |
| `e2_gemma_patch_tasks.csv`, `e2_gemma_selection.csv` | per-task E2 summary; greedy / random / visible-test selection per task | same |
| `ab_summary.json` | dev-set A/B summary (two seeds) | `06_agent_ab/grade_ab.py` |

`ab_summary.json` was transcribed from the grading notebook's printed output; rerunning `grade_ab.py` on the A/B archive writes the same file with full precision. The competition-dev-set results (Steps 8-13) are regenerated by the notebooks from the competition data, which cannot be redistributed here.
